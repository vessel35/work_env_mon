# YouTubeGuard

macOS 에서 정해진 시간에 YouTube, 넷플릭스, 디즈니+ 같은 사이트 접속을 막는
프로그램입니다. 막을 서비스는 목록에서 고르고, 목록에 없는 곳은 주소를 직접
적어 넣습니다. Swift 로만 만들었고 외부 라이브러리를 쓰지 않습니다.

## 어떻게 생겼나

두 조각으로 나뉩니다.

**차단 데몬** 은 관리자 권한으로 배경에서 돕니다. 3 초마다 지금이 차단할
시간인지 따져 보고, 그렇다면 `/etc/hosts` 안에 표시선으로 감싼 구간을 넣어
고른 사이트의 주소를 막습니다. 시간이 지나면 그 구간만 걷어 냅니다. 이름 조회 자체를
막는 방식이라 브라우저뿐 아니라 YouTube 앱을 포함한 모든 프로그램에 함께
적용됩니다.

**메뉴 바 앱** 은 일반 사용자 권한으로 돌면서 방패 모양 아이콘을 띄웁니다.
지금 상태를 보여 주고, 켜고 끄거나 시간을 고칠 수 있게 합니다.

둘은 설정 파일 하나를 사이에 두고 이야기합니다. 설정 폴더에만 admin 그룹
쓰기 권한을 주었기 때문에, 설치할 때 한 번만 관리자 비밀번호가 필요하고
이후 켜고 끄는 일상 조작에는 비밀번호를 묻지 않습니다.

## 설치

```bash
./build.sh
```

```bash
sudo ./install.sh
```

`build.sh` 는 검사 프로그램을 먼저 돌리고 나서 데몬과 앱을 빌드합니다.
`install.sh` 는 설치 전에 `/etc/hosts` 와 `/etc/pf.conf` 를 백업합니다.

지울 때는 이렇게 합니다. 차단을 모두 풀고 넣었던 파일을 되돌립니다.

```bash
sudo ./uninstall.sh
```

## 아이콘으로 보는 상태

메뉴 바 아이콘은 네 상태가 모두 방패 하나의 변주입니다. 채운 방패는 지금
무언가를 하고 있다는 뜻이고, 선으로만 그린 방패는 지켜보고만 있다는 뜻입니다.
색을 구별하기 어려운 경우에도 이 차이와 방패 안의 모양으로 알아볼 수 있습니다.

| 아이콘 | 색 | 뜻 |
|---|---|---|
| 채운 방패에 가로 막대가 뚫림 | 빨강 | 지금 차단하고 있습니다 |
| 선 방패 안에 재생 삼각형 | 초록 | 차단 기능은 켜져 있고, 지금은 허용 시간입니다 |
| 선 방패에 사선이 지남 | 회색 | 차단 기능이 꺼져 있습니다 |
| 채운 방패에 느낌표가 뚫림 | 주황 | 차단 데몬이 응답하지 않습니다 |

도형은 시스템 심볼이 아니라 `src/icon/IconArt.swift` 에 24px 격자로 직접
그렸습니다. 그릴 때마다 다시 그리므로 어떤 크기에서도 또렷합니다. 앱 번들 아이콘은 방패에 재생 삼각형을 뚫은 모양이며, 빌드할 때
같은 코드에서 낱장을 그려 `.icns` 로 묶습니다.

색이 제대로 나오는지 확인하려면 이렇게 합니다.

```bash
/Applications/YouTubeGuard.app/Contents/MacOS/YouTubeGuard --icon-check
```

아이콘 위에 마우스를 올리면 언제 풀리는지, 몇 개의 주소를 막고 있는지가
설명으로 나옵니다. 메뉴를 열면 맨 위에 같은 내용이 한 줄로 들어 있습니다.

## 메뉴에서 할 수 있는 일

차단 기능을 통째로 켜고 끌 수 있고, 시간표와 무관하게 지금부터 30 분에서
4 시간까지 바로 막을 수 있습니다. 반대로 차단 시간 중에 5 분에서 1 시간까지
잠시 풀어 둘 수도 있으며, 정한 시간이 지나면 저절로 원래대로 돌아옵니다.
즉시 차단이나 일시 해제가 걸려 있는 동안에는 그것을 그만두는 항목이 메뉴에
따로 나타납니다.

**켜고 끄는 조작과 설정 변경은 모두 확인 창을 한 번 거칩니다.** 확인 창의
기본 단추는 "취소" 쪽에 두었기 때문에, 실수로 Return 을 눌러도 그냥 진행되지
않습니다.

## 차단 시간 적는 법

메뉴의 "차단 시간 편집" 을 열면 한 줄에 구간 하나씩 적는 창이 나옵니다.

```
평일 09:00-18:00
월,수,금 20:00-23:00
매일 23:00-06:00
```

요일은 `월 화 수 목 금 토 일` 을 쓰고, `매일`, `평일`(= `주중`), `주말` 같은
묶음말도 됩니다. `월-금` 처럼 범위로 적어도 되고 `금-월` 처럼 주를 넘어가도
됩니다. `#` 으로 시작하는 줄과 빈 줄은 건너뜁니다.

끝 시각이 시작 시각보다 앞서면 자정을 넘어 다음 날까지 이어집니다. 위 예의
`매일 23:00-06:00` 은 밤 11 시부터 다음 날 아침 6 시까지를 뜻합니다. 시작과
끝을 같게 적으면 그 요일 하루 종일이 되며, `00:00-24:00` 으로 적어도 같습니다.

잘못 적으면 저장되지 않고 몇 번째 줄이 왜 틀렸는지 창 안에 빨간 글씨로
나옵니다. 겹치는 구간을 적어도 괜찮습니다. 알아서 하나로 합쳐 다룹니다.

## 무엇을 막을지 고르기

메뉴의 "차단 시간 편집" 을 열면 창 위쪽에 탭이 두 개 있습니다. "차단 시간" 은
언제 막을지를, "차단 대상" 은 무엇을 막을지를 정하는 곳입니다.

### 서비스 고르기

목록에서 골라 체크하면 됩니다. 처음 설치하면 YouTube 만 켜져 있습니다.

YouTube, 넷플릭스, 디즈니+, 티빙, 웨이브, 쿠팡플레이, 왓챠, 프라임 비디오,
Apple TV+, 트위치 를 고를 수 있습니다.

각 서비스는 그 서비스로 들어가는 입구만 막습니다. **같은 회사의 다른 서비스는
건드리지 않습니다.** 프라임 비디오를 막아도 아마존 쇼핑은 그대로 쓸 수 있고,
쿠팡플레이를 막아도 쿠팡 쇼핑은 그대로입니다. YouTube 를 막아도 구글 검색과
지메일은 정상입니다. 이 점은 검사 프로그램이 매번 확인합니다.

체크 상자 위에 마우스를 올리면 그 서비스에서 실제로 막는 주소를 몇 개
보여 줍니다.

### 주소를 직접 적기

목록에 없는 곳은 같은 탭 아래쪽 칸에 한 줄에 하나씩 적습니다.

```
instagram.com
news.example.com
```

주소를 붙여 넣어도 됩니다. `https://www.netflix.com/browse?x=1` 처럼 적으면
`www.netflix.com` 만 알아서 남깁니다. 대소문자와 포트 번호, 경로도 정리합니다.

hosts 파일은 하위 도메인을 한 번에 막지 못하므로, **적어 준 주소와 `www.` 를
붙인 형태를 함께 막습니다.** `example.com` 이라고 적으면 `www.example.com` 도
같이 막힙니다.

`#` 으로 시작하는 줄과 빈 줄은 건너뜁니다. 잘못 적으면 저장되지 않고 몇 번째
줄이 왜 틀렸는지 창 아래에 빨간 글씨로 나옵니다. `localhost` 나 IP 주소처럼
막으면 곤란한 것은 거절합니다.

### 함께 적용할 설정

체크 상자 세 개가 고른 대상 전체에 함께 적용됩니다.

**영상 전송 호스트도 함께 막기** 는 다른 사이트에 끼워 넣은 재생 창까지
막습니다. 기본으로 켜져 있습니다.

**브라우저의 암호화 DNS 우회 막기** 는 크롬이나 파이어폭스가 자체 암호화
DNS 를 써서 `hosts` 파일을 건너뛰는 것을 막습니다. 차단 시간에만 적용되며,
이름 조회 경로를 시스템 쪽으로 되돌릴 뿐이라 다른 사이트 접속에는 지장이
없습니다. 기본으로 켜져 있습니다.

**방화벽으로 IP 까지 막기** 는 pf 방화벽으로 주소를 직접 막습니다. 더
확실하지만 주소가 같은 회사의 다른 서비스와 겹치는 경우 그쪽까지 막힐 수 있어
**기본으로 꺼져 있습니다.**

지금 무엇을 막도록 되어 있는지는 메뉴를 열면 두 번째 줄에 나옵니다.

## 알아 둘 한계

이름 조회를 막는 방식이라 몇 가지 빈틈이 있습니다. 감추지 않고 적어 둡니다.

`hosts` 파일은 하위 도메인 전체를 한 번에 막지 못합니다. 실제 영상 데이터가
내려오는 `rr1---sn-xxxx.googlevideo.com` 이나 넷플릭스의 `*.nflxvideo.net` 같은
주소는 매번 달라져서 목록으로 적을 수 없습니다. 다만 입구가 막히면 그 주소를
받아 올 일 자체가 없으므로 평소 쓰기에는 문제가 되지 않습니다.

브라우저가 특정 암호화 DNS 서버를 직접 지정해 두고 실패해도 시스템 쪽으로
되돌아오지 않도록 설정되어 있으면 뚫릴 수 있습니다. 브라우저 설정에서 보안
DNS 를 끄면 확실합니다.

iCloud 비공개 릴레이를 켜 두면 사파리 통신이 애플 프록시를 거치므로 우회될
수 있습니다. VPN 을 켜도 마찬가지입니다.

이 프로그램은 자기 통제를 돕는 도구이지 다른 사람을 막는 장치가 아닙니다.
관리자 계정을 쓰는 사람은 메뉴에서 언제든 끌 수 있습니다. 확인 창을 한 번
거치게 해 두었을 뿐 강제로 잠그는 장치는 없습니다.

## 파일이 놓이는 곳

차단 데몬은 `/usr/local/libexec/ytguardd` 에, 메뉴 바 앱은
`/Applications/YouTubeGuard.app` 에 놓입니다. 설정은
`/Library/Application Support/YouTubeGuard/user/config.json` 이고, 현재 상태는
같은 폴더 위쪽의 `state.json` 에 데몬이 적습니다. 기록은
`/Library/Logs/YouTubeGuard/daemon.log` 에 쌓이며 메뉴의 "기록 보기" 로 열 수
있습니다.

자동 실행 등록은 `/Library/LaunchDaemons/com.vincent.ytguard.daemon.plist` 와
`/Library/LaunchAgents/com.vincent.ytguard.menubar.plist` 입니다.

## 문제가 생겼을 때

### 메뉴 바에 방패 아이콘이 보이지 않는다

먼저 앱이 실제로 돌고 있는지 봅니다.

```bash
pgrep -lf YouTubeGuard
```

프로세스가 있는데도 메뉴 바에 없다면 자리가 모자라 잘린 것입니다. 새로 붙는
아이콘은 맨 왼쪽에 앉는데, 메뉴 바가 가득 차면 왼쪽부터 잘려 나갑니다. 노치가
있는 내장 화면은 아이콘이 들어갈 폭이 특히 좁아서, 이 프로그램이 없어도 이미
몇 개가 잘려 있는 경우가 많습니다.

자리를 비워 주어야 합니다. Command 키를 누른 채로 아이콘을 옆으로 끌면 순서를
바꿀 수 있고, 메뉴 바 밖으로 끌어내면 없앨 수 있습니다. YouTubeGuard 아이콘을
오른쪽으로 옮겨 두면 잘리지 않고, 그 자리는 다음 실행에도 남습니다. 시스템
설정의 제어 센터 항목에서 쓰지 않는 아이콘을 숨겨도 됩니다.

외장 모니터를 쓰고 있다면 그쪽 메뉴 바에는 보일 수 있습니다. 화면마다 들어가는
개수가 다르기 때문입니다.

아이콘을 닫았거나 실수로 없앴다면 응용 프로그램 폴더의 YouTubeGuard 를 다시
실행하면 됩니다. 아이콘이 없어도 차단 자체는 계속 동작합니다.

### 차단 시간인데 브라우저에서 YouTube 가 열린다

먼저 차단이 시스템에 걸려 있는지 확인합니다. 아래에서 유튜브는 실패하고
구글은 200 이 나오면 차단은 정상입니다.

```bash
curl -s -o /dev/null -w "%{http_code}\n" --max-time 5 https://www.youtube.com
```

차단이 정상인데도 브라우저에서 열린다면 브라우저 쪽이 이전 것을 붙들고 있는
것입니다. 브라우저는 시스템과 별개로 자체 이름 조회 캐시를 두고, 이미 맺어 둔
연결도 한동안 그대로 씁니다. **브라우저를 완전히 종료했다가(Command-Q) 다시
열면** 해결됩니다. 크롬은 주소창에 `chrome://net-internals/#dns` 를 넣고
캐시를 비워도 됩니다.

그래도 열린다면 브라우저의 보안 DNS 설정을 봅니다. 크롬은 설정의 개인 정보
보호 및 보안 항목에, 파이어폭스는 개인 정보 및 보안 항목에 있습니다. 특정
공급자를 직접 지정해 두었다면 끄거나 자동으로 되돌려 주세요.

사파리를 쓰면서 iCloud 비공개 릴레이를 켜 두었다면 통신이 애플 프록시를
거치므로 우회됩니다. VPN 을 켜도 마찬가지입니다.

### 그 밖의 확인

지금 상태를 확인하려면 이렇게 합니다.

```bash
sudo /usr/local/libexec/ytguardd --status
```

차단이 어떤 이유로든 남아 있어 곤란하면 이 명령으로 곧바로 풉니다.

```bash
sudo /usr/local/libexec/ytguardd --clear
```

데몬이 도는지 확인하려면 이렇게 합니다.

```bash
sudo launchctl print system/com.vincent.ytguard.daemon | head -20
```
## 코드 구조

`src/shared` 에는 데몬과 앱이 함께 쓰는 것이 들어 있습니다. 설정과 상태를
담는 자료형(`Model.swift`), 시간 판정(`Schedule.swift`), 규칙 문장을 읽고
쓰는 곳(`RuleText.swift`), 상태 문구(`StatusText.swift`) 입니다.
막을 수 있는 서비스 목록은 `Services.swift`, 직접 적어 넣는 주소를 다듬고
검사하는 곳은 `HostName.swift`, 둘을 합쳐 실제 차단 목록을 만드는 곳은
`Blocklist.swift` 입니다.

`src/daemon` 에는 차단을 실제로 거는 쪽이 있습니다. `hosts` 파일 다루기,
pf 방화벽 다루기, 그리고 3 초마다 도는 본체입니다.

`src/menubar` 에는 아이콘과 메뉴, 확인 대화상자, 편집 창이 있습니다.
`src/icon` 에는 아이콘 도형과 색이 있습니다. 메뉴 바 앱과 앱 번들 아이콘을
그리는 도구가 같은 도형을 씁니다.

`tests` 의 검사 프로그램은 관리자 권한 없이 돌아가며 시간 판정과 규칙 해석,
`hosts` 구간 넣고 빼기를 확인합니다. `build.sh` 가 빌드 전에 자동으로
돌리므로 따로 실행할 필요는 없습니다.

```bash
./build/ytguard-tests
```
